# FortBoost AI — règles permanentes

1. Le dépôt officiel est exclusivement `SculptMethod/fortboostai`.
2. Ne jamais modifier `SculptMethod/fortboost` pour ce projet.
3. Enregistrer toutes les modifications dans `fortboostai`.
4. Consulter le code existant avant chaque modification.
5. Conserver une architecture propre et centralisée.
6. Ne jamais créer inutilement un deuxième projet.
7. Tester avant publication.
8. Respecter l'identité visuelle, les fonctionnalités et les traductions FR/EN.
9. Ne jamais publier de secrets ni de données privées.
10. Résumer les fichiers modifiés et les tests effectués.
11. Utiliser `fortboostai` comme référence dans les sessions futures.
12. Ne jamais changer de dépôt officiel sans autorisation explicite.

## Principes
- Application Windows en développement : aucun téléchargement factice.
- Aucun benchmark ou gain de FPS inventé ; aucun bénéfice garanti.
- Paiements réels désactivés jusqu'à validation commerciale, technique et juridique.
- Licences attribuées uniquement sur webhook Stripe vérifié côté serveur.
- Modifier sur une branche, proposer une pull request et préserver `main`.
- Ne jamais confondre latence réseau et input lag local.
